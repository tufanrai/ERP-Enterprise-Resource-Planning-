# Stakeholder Overview

> **Status:** Draft · **Owner:** Project Manager · **Audience:** Leadership, investors, department heads, anyone new to the project
> **Reading time:** 5 minutes

This page explains the project on one screen. If you only read one document, read this one.

## What are we building?

A cloud-based **Enterprise Resource Planning (ERP)** system sold as a subscription (SaaS). It brings a company's finance, inventory, sales, purchasing, HR and reporting into one place, so everyone works from the same data.

## Why?

Growing businesses run on disconnected tools and spreadsheets. Traditional ERP is too expensive and slow to adopt. We offer an ERP that is affordable, modular and quick to set up. Full reasoning is in the [Vision and business case](01-vision-and-business-case.md).

## Who is it for?

Small and mid-sized companies (10–500 employees) that are outgrowing basic tools. See [Personas](../product/02-personas-and-user-journeys.md).

## What will it do? (launch scope)

| Module | What it covers | Launch phase |
|---|---|---|
| Platform core | Tenants, users, roles, settings, audit log, notifications | MVP |
| Finance & Accounting | Chart of accounts, journals, invoices, bills, payments, tax, financial reports | MVP |
| Inventory | Products, warehouses, stock movements, valuation, reorder alerts | MVP |
| Sales | Customers, quotes, sales orders, delivery, invoicing | MVP |
| Purchasing | Suppliers, purchase requests, purchase orders, receiving | Phase 2 |
| HR & Payroll | Employees, attendance, leave, payroll runs | Phase 3 |
| Reporting & Analytics | Dashboards, custom reports, exports | MVP (basic), Phase 3 (advanced) |
