# ERP — Enterprise Resource Planning (SaaS)

A modular, multi-tenant cloud ERP for small and mid-sized businesses: finance, inventory, sales, purchasing, HR and reporting in one place.

> **Project status:** Discovery. Documentation is in place; the codebase has not been scaffolded yet.
